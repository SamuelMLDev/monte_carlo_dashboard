1. `study-design.png` — Study Design page showing the mathematical DGP and factor explorer.
2. `results-summary.png` — Study Summary header plus estimator comparison table with MCSE columns.
3. `diagnostics-overlap.png` — propensity overlap and covariate-balance plots.
4. `method-stress-test.png` — RMSE and coverage robustness profile across stress levels.
5. `reproducibility-manifest.png` — seed hierarchy and manifest preview.

Use a neutral light theme and avoid including local filesystem paths or other machine-specific information in published captures.
